Remove this import from the library

Removal makes the listed files unavailable to everyone with access to this music. You review the files first, and Restore brings them back.

What removal keeps

Stop only ends unfinished importing; removal is a separate reviewed action. Copies already downloaded to a device stay there.

Removed originals are retained privately on this server. Restore puts the same bytes and tags back at the same paths, keeping native IDs and saved references. Removal does not free disk space. Personal history, library choices, favorites and playlists are kept; removed songs are unavailable until restored.
